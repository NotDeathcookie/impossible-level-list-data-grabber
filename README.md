# ill-data-grabber
DISCLAIMER!! THE PYTHON FILE IS VIBECODED; however, the .json and .csv output files are data simply fetched from the ILL's API with the information ordered according to the vibecoded script
This repo acts as a way to simply download all data accessible from ILL's API on specific levels on the [Impossible Levels List]([https://impossiblelevels.com/]) with the top 2000 levels used as examples
